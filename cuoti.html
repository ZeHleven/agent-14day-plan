Agent 面试错题集

陪练规则：答得不好 → 记入本题 + 精简正解。复习时优先翻这里。

D1 · 90 秒项目骨架（定稿可背）

我们做的是造价侧的智能报价 + 智能投标。报价要解决询价查价写价繁琐：清单项先定额库匹配，匹配不上再 AI 估价出单——路径相对固定，用 Workflow；正则松紧影响精确度与召回，我们用可信度标注把边界讲清，不把整段吹成 Agent。

投标才是 Agent：解析招标 Word/PDF 和企业资料，抽风险、技术、地区、工程量，对照乙方承受度、利润、技术匹配、产能与覆盖，动态判断能否接标，再按标书要求生成投标文件。资料进 Context，工具解析 → 观察 → 再判断 → 需要时 RAG 按需检索企业资料 → 决策后调用生成工具出标书。

坏例：资质曾按固定字数切 chunk，段落被切断，RAG 只拿到半截，模型误判资质不足。定位看召回片段后，改为按标题/段落语义切并加 overlap，资质类整段入库，误判明显下降。

D1 · 易偏点
题目你的偏法精简正解
Agent vs API 只说能 chat 又能 work API=无状态一问一答；Agent=感知→规划→行动→观察→再决策的闭环，直到完成或熔断
90 秒骨架 只讲报价 Workflow / 或只讲 RAG 技术点 报价=Workflow；投标=Agent；必须含坏例（现象→定位→解决→效果）
